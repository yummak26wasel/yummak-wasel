  2. Build ← Firestore Database ← Create database ← Start in test mode
  3. Project settings ⚙️ ← Your apps ← Web </>
  4. انسخ firebaseConfig والصقه بأعلى ملف index.html
  5. لتفعيل إشعارات الهاتف المسكّر: افتح ملف TELEGRAM.md واتبع الخطوات
